Quick Start

Get trading in under a minute. Install from npm, configure your wallet, and execute your first trade.

1. Install

# From npm (recommended)
npm install -g outsmart@alpha

# Or from source
git clone https://github.com/outsmartchad/outsmart-cli.git
cd outsmart-cli
npm install --legacy-peer-deps
npm run build

2. Configure

outsmart init

Prompts for your wallet key and RPC endpoint. Config is saved to ~/.outsmart/config.env. You only need to do this once.

3. Trade

# Buy tokens (token auto-detected from pool)
outsmart buy --dex raydium-cpmm --pool <POOL> --amount 0.1

# Sell 100% of held balance
outsmart sell --dex raydium-cpmm --pool <POOL> --pct 100

# Swap aggregator (no pool needed)
outsmart buy --dex jupiter-ultra --token <MINT> --amount 0.1

# Preview without sending (dry-run)
outsmart buy --dex raydium-cpmm --pool <POOL> --amount 0.1 --dry-run

# Check balances
outsmart balance

Commands

Full command reference for trading, wallet management, liquidity, and pool creation.

Trading

outsmart buy

Buy tokens with SOL (or a quote token). On-chain DEXes require --pool; aggregators require --token.

outsmart buy --dex raydium-cpmm --pool <POOL> --amount 0.1
outsmart buy --dex jupiter-ultra --token <MINT> --amount 0.5
FlagDescription
-d, --dex <name>DEX adapter name (required)
-a, --amount <sol>SOL amount to spend (required)
-p, --pool <address>Pool address (required for on-chain DEXes)
-t, --token <mint>Token mint (auto-detected from pool; required for aggregators)
--dry-runSimulate only — preview CU usage without sending

outsmart sell

Sell a percentage of your held token balance.

outsmart sell --dex raydium-cpmm --pool <POOL> --pct 100
outsmart sell --dex jupiter-ultra --token <MINT> --pct 50
FlagDescription
-d, --dex <name>DEX adapter name (required)
--pct <percentage>Percentage of balance to sell, 1-100 (required)
-p, --pool <address>Pool address (required for on-chain DEXes)
-t, --token <mint>Token mint (auto-detected from pool; required for aggregators)
--dry-runSimulate only — preview CU usage without sending

outsmart quote

Get the current on-chain price from a pool.

outsmart quote --dex raydium-cpmm --pool <POOL>

outsmart find-pool

Discover a pool for a token pair on a specific DEX.

outsmart find-pool --dex raydium-cpmm --token <MINT>

Liquidity

outsmart add-liq

Add liquidity. Supports one-sided SOL, one-sided token, or balanced deposits.

outsmart add-liq --dex meteora-dlmm --pool <POOL> --amount-sol 0.5 --strategy spot --bins 50
outsmart add-liq --dex meteora-damm-v2 --pool <POOL> --amount-sol 1.0
FlagDescription
--amount-sol <n>SOL to deposit
--amount-token <n>Non-SOL token to deposit
--strategy <type>spot | curve | bid-ask (DLMM only, default: spot)
--bins <count>Number of bins (DLMM only, default: 50, max: 70)

outsmart remove-liq / claim-fees / positions

outsmart remove-liq --dex meteora-damm-v2 --pool <POOL> --pct 100
outsmart claim-fees --dex meteora-dlmm --pool <POOL>
outsmart positions --dex meteora-dlmm --pool <POOL>

Pool Creation

outsmart create-pump-coin

Create a new PumpFun token with a bonding curve.

outsmart create-pump-coin --name "My Token" --symbol "MYTKN" --uri "https://ipfs.io/..."

outsmart create-pool

Create a PumpSwap AMM pool with initial liquidity.

outsmart create-pool --base <MINT> --quote So111...112 --base-amount 1000000 --quote-amount 1

outsmart create-damm-pool

Create a Meteora DAMM v2 custom pool with full fee configuration.

outsmart create-damm-pool --base <MINT> --base-amount 1000000 --quote-amount 0.5 \
  --max-fee 5000 --min-fee 100 --fee-mode 1 --dynamic-fee

Stablecoin Auto-Swap

Some pools use USDC, USDT, or USD1 as the quote token. The CLI handles the conversion automatically.

On Buy

Detects stablecoin quote from pool state, swaps SOL to stablecoin, then buys the token. All in one command.

On Sell

Sells token for stablecoin, then auto-converts proceeds back to SOL. No manual steps needed.

# LaunchLab pool quoted in USD1 — just specify SOL amount
outsmart buy --dex raydium-launchlab --pool <POOL> --amount 0.1
# → auto-swaps 0.1 SOL → USD1 → buys token

Uses Jupiter Ultra if JUPITER_API_KEY is set, otherwise falls back to on-chain DEX pools.

Programmatic API

Use outsmart as a library in your own bots, scripts, or agents.

import { getDexAdapter, listDexAdapters } from "outsmart";

// Import adapters you need (self-registers on import)
import "outsmart/dist/dex/raydium-cpmm";
import "outsmart/dist/dex/jupiter-ultra";

const cpmm = getDexAdapter("raydium-cpmm");

// Buy
const result = await cpmm.buy({
  tokenMint: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  amountSol: 0.1,
  opts: { slippageBps: 300, tipSol: 0.001 },
});

// Sell 100%
const sellResult = await cpmm.sell({
  tokenMint: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  percentage: 100,
});

// Get price
const price = await cpmm.getPrice!("POOL_ADDRESS");

// List all adapters
const adapters = listDexAdapters();

For AI agent integration (MCP server, OpenClaw workflows), see outsmart-agent.

Architecture

Clean adapter pattern with self-registration. Each DEX module implements IDexAdapter and registers itself on import.

Adapter Pattern

Each DEX module implements IDexAdapter (buy, sell, getPrice, findPool, addLiquidity, etc.) and self-registers via registerAdapter(). The CLI and library access adapters through the DexRegistry.

TX Simulation

Transactions are simulated before sending by default. Failed simulations return immediately without spending SOL. Use --dry-run to preview CU usage.

RPC Resilience

Exponential backoff on transient RPC errors (429, 503, network). Blockhash expiry retry with fresh blockhash. Configurable retry limits.

Multi-Wallet

Wallets stored in ~/.outsmart/wallets.json with owner-only permissions. Add, switch, and remove wallets without restarting.

Testing

CI-safe unit tests run without RPC. Mainnet integration tests use real transactions with tiny amounts.

# CI-safe (no RPC or SOL needed)
npm run test:unit        # 43 unit tests
npm run test:registry    # 18 adapters registered

# Mainnet integration (requires PRIVATE_KEY + MAINNET_ENDPOINT)
npm run test:raydium     # Raydium AMM v4, CPMM, CLMM
npm run test:meteora     # Meteora DAMM v2, DLMM, DBC
npm run test:pumpfun     # PumpFun + PumpSwap
npm run test:orca        # Orca Whirlpool
npm run test:clmm        # Byreal + PancakeSwap CLMM
npm run test:fusion      # Fusion + Futarchy AMM
npm run test:api         # Jupiter Ultra + DFlow

Mainnet tests use 0.02 SOL per buy. Run suites one at a time — tests share a wallet.
